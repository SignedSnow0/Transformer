# Reinvent the Wheel - Transformer (1 person)

Implement the whole Transformer (encoder and decoder) and use it on data of your choice (a toy example is good enough). Only simple primitives (e.g., linear transformation) can be reused to implement your model.

You can write only the forward pass.

To see an example of how transformer encoders are being utilized, read the BERT paper (in references below).

**Evaluation note**: At the end, we will review the implementation and documentation together. Points will be assigned according to presented knowledge.
